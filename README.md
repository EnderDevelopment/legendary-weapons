# Legendary Weapons

Legendary Weapons is a Minecraft plugin that adds powerful and unique weapons to your game. This plugin introduces the God Sword, a legendary weapon that deals massive damage and has special enchantments. The plugin is designed to enhance your gameplay with these powerful tools.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Obtain the God Sword by crafting it or using a command.
2. Equip the God Sword in your inventory.
3. Use the God Sword to deal massive damage to your enemies.
